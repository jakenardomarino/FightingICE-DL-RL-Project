## How to run DareFightingICEI'm going to assume you're using Windows. If not, you'll have to look at the `.bat` files I talk about and make equivalent files/commands for your OS.* `training.bat` will run the game in training mode, without logging anything. This is useful for understanding how to play the game. It is not useful for collecting data.* `log.bat` will run one game (with 3 rounds) and log it. This is useful to test changes quickly.* `log-100-rounds.bat` will DELETE all existing log files in `log/`, run 100 rounds between two AIs, and log that. To change the two AIs, edit the file itself.All of these batch files have comments in them if you want to modify them.## How to modify CustomTOVORGo to `AI Source Code/Custom TOVOR/`. You can open `CustomTOVOR.java` there and edit it to your heart's content. The instructions to compile CustomTOVOR into a usable jar file, along with where to put that file, are in `AI Source Code/Custom TOVOR/make.txt`.
